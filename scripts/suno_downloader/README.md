# Suno AI Audio Pipeline & Quality Suite (Audingo)

مجموعة أدوات أوتوماتيكية متكاملة للاتصال بمتصفح Opera/Chrome عبر بروتوكول Chrome DevTools (CDP)، لسحب الأغاني والنسخ المتعددة من Suno AI بأعلى جودة صوتية ممكنة، وفك التشفير في الذاكرة الحية بدون قيود التنزيل اليومية (0 Download Quota consumption)، مع مطابقة التوقيت بالثانية وفحص خلو الصوت من أي تشويش أو تشويه.

---

## 📁 محتويات الحزمة (`scripts/suno_downloader/`)

1. **`suno_downloader.py`**:
   - المحرك الأساسي للسحب الآلي.
   - يعتمد تقنية حقن خطاف `SourceBuffer.prototype.appendBuffer` لالتقاط دفق الصوت الأصلي المفكوك تشفيره مباشرة من مشغل المتصفح.
   - يعتمد تقنية **Active-Seek** لتحفيز مشغل المتصفح على تحميل وفك تشفير 100% من تدفق الصوت دون الحاجة للانتظار بالوقت الحقيقي (يستغرق سحب أغنية مدتها 3 دقائق حوالي 4 إلى 5 ثوانٍ فقط).
   - تحويل فوري عبر FFmpeg إلى صيغة `M4A` (AAC LC, 160 kbps, 48,000 Hz Stereo) مدمجاً بها علم `+faststart` وميتا داتا نظيفة تماماً مهيأة للبث الفوري على Cloudflare R2 ومتوافقة مع Windows Explorer.

2. **`generate_manifest.py`**:
   - سكربت فحص عميق يمسح كافة نسخ الأغاني الـ 133 على سونو.
   - يستخرج مدة كل نسخة بدقة (`mm:ss`) ويقارنها مع مدة الملفات المحلية عبر `ffprobe`.
   - يولد ملف التقرير المرجعي `suno_library_manifest.json`.

3. **`verify_full_library.py`**:
   - أداة المطابقة الزمنية الصارمة للتأكد من أن جميع ملفات المكتبة مطابقة بنسبة 100% لتوقيت سونو الأصلي (فارق <= ثانيتين)، ورصد أي ملف مبتور أو ناقص أو زائد.

4. **`audit_all_glitches.py`**:
   - فاحص الجودة الصوتي الذكي بالمرحلتين:
     - **المرحلة الأولى:** فحص سلامة الحاويات والفك (Demux & Frame Integrity).
     - **المرحلة الثانية:** تحليل الإشارات الرقمية وعينات القطع (Clipping Rate & High-Frequency Noise Ratios) لكشف أي تشويش أو خلل ترددي ("عفاريت").

5. **`organize_suno_audingo.py`**:
   - منظم المجلدات والملفات وتصحيح مطابقة أرقام النسخ مع المجلدات بحسب قاعدة البيانات المحلية.

6. **ملفات التشغيل السريع (`.bat`)**:
   - **`start_opera.bat`**: تشغيل متصفح Opera بوضع تصحيح الأخطاء عن بُعد على المنفذ `9222`.
   - **`run_downloader.bat`**: تشغيل سكربت السحب بنقرة واحدة بأعلى أولوية مسار بايثون.
   - **`Organize_Songs.bat`**: تشغيل سكربت التنظيم بنقرة واحدة.

7. **ملفات البيانات المرجعية**:
   - **`songs.json`**: قائمة الأغاني الـ 133 المتطابقة مع ترتيب `ngsl_vocab.db`.
   - **`suno_library_manifest.json`**: مانيفست شامل بـ 522 نسخة موثقة بتواقيتها الدقيقة وحالتها.

## 🚀 طريقة الاستخدام

### الخطوة 1: تشغيل المتصفح بوضع التصحيح (CDP)
قم بتشغيل ملف `start_opera.bat` (أو تشغيل المتصفح بالأمر):
```cmd
opera.exe --remote-debugging-port=9222
```
وتأكد من تسجيل الدخول إلى حسابك في `https://suno.com/create`.

### الخطوة 2: تشغيل السحب الآلي
قم بتشغيل ملف `run_downloader.bat` أو تشغيل الأمر:
```bash
python scripts/suno_downloader/suno_downloader.py
```

### الخطوة 3: التحقق ومراجعة الجودة
- للتحقق من مطابقة التوقيت:
  ```bash
  python scripts/suno_downloader/verify_full_library.py
  ```
- لفحص خلو الملفات من أي تشويش صوتي:
  ```bash
  python scripts/suno_downloader/audit_all_glitches.py
  ```
